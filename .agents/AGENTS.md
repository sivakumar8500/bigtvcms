# Project Rules - BigTVCMS

## 1. Multilingual Content / Static Text
* **Four Language Requirement**: Any static text added to the application must support all four official languages:
  * English (`en`)
  * Telugu (`te`)
  * Hindi (`hi`)
  * Malayalam (`ml`)
* Avoid hardcoded inline strings. Always use localized translations.

## 2. Theming & Accessibility
* **Theme Support**: All newly built features and visual interfaces must fully support both **Light Theme** and **Dark Theme** using standard theme tokens.

## 3. Testing and Code Coverage
* **Unit Testing**: Implement test cases for newly added component views, controllers, hooks, and helpers.
* **Code Coverage Threshold**: The overall statement, line, branch, and function code coverage must be maintained above **80%**.
